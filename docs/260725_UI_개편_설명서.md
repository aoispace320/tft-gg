# 프론트엔드 UI 개편 설명서 (2026-07-25)

> op.gg(https://op.gg/ko/tft) 와 lolchess.gg(https://lolchess.gg/) 의 UI를 참고해서
> 우리 프론트엔드의 디자인 테마와 홈 화면을 개편한 작업 정리입니다.

---

## 1. 실행 방법 (먼저 읽기)

```bash
cd frontend
npm install     # 처음 한 번만
npm run dev     # http://localhost:5173 에서 열림
```

- 아직 백엔드 연동 전이라 **모든 데이터는 목(mock) 데이터**입니다 (`src/mocks/`).
- 확인 명령어:
  - 타입 체크: `npm run typecheck`
  - 테스트: `npm test`
  - 둘 다 통과된 상태로 마무리했습니다.

---

## 2. 무엇이 바뀌었나 (요약)

| 항목 | 이전 | 이후 |
|---|---|---|
| 전체 테마 | LoL 헥스텍 풍 (남색 배경 + 금색 포인트 + 세리프 폰트) | op.gg 풍 모던 다크 (짙은 회색 배경 + 파란색 포인트 + 산세리프) |
| 홈(`/`) | 통계 페이지로 리다이렉트만 함 | **홈페이지 신설** — 대형 검색바 + 추천 메타 + 랭킹 TOP 10 |
| 헤더(네비게이션) | 탭 가운데 정렬, 금색 밑줄 | op.gg처럼 로고 옆 좌측 정렬, 파란색 활성 바, "홈" 탭 추가 |
| 검색바 | 사각형 다크 인풋 | op.gg 시그니처인 **알약(라운드 필) 형태**, 홈에서는 흰색 대형 바 |
| 티어 배지(S~D) | 빨강/주황/크림/하늘/회색 | lolchess 풍 빨강/주황/노랑/초록/회색 |

## 3. 어떤 사이트에서 뭘 참고했나

### op.gg 에서 가져온 것
- **다크 그레이 테마**: 배경 `#1C1C1F`, 카드 `#28282C`, 포인트 블루 `#5383E8`
- **히어로 검색바**: 홈 상단에 큰 로고 + 흰색 대형 검색바 (지역 선택 + "플레이어 이름 + #KR1" + `.GG` 버튼)
- **헤더 레이아웃**: 로고 옆에 탭 좌측 정렬, 활성 탭은 하단에 파란 바

### lolchess.gg 에서 가져온 것
- **홈 2단 구성**: 왼쪽 "추천 메타" 리스트 + 오른쪽 "랭킹 TOP 10" 테이블
- **추천 메타 행 디자인**: 티어 배지(S/A/B...) + 조합 이름 + 유닛 아이콘(코스트별 테두리 색) + 평균 등수/픽률
- **랭킹 테이블**: 순위/소환사/티어/LP/승률, 행 클릭 시 소환사 페이지로 이동

## 5. 핵심 아이디어: 색 토큰 재매핑 (꼭 이해하고 넘어가기)

기존 코드 33개 파일이 `text-gold`, `bg-gold`, `text-teal` 같은 클래스를 쓰고 있었습니다.
이걸 파일마다 전부 고치는 대신, **tailwind.config.js 에서 색 "값"만 바꿔서** 전체 앱을 한 번에 리스킨했습니다.

```
클래스 이름        이전 값(금색 계열)   →   현재 값(파란색 계열)
─────────────────────────────────────────────────────
gold              #C8AA6E             →   #5383E8 (op.gg 블루)
gold-bright       #F0E6D2             →   #EBEEF1 (거의 흰색)
teal              #0AC8B9             →   #00BBA3
bg-base           #0A1428 (남색)      →   #1C1C1F (짙은 회색)
```

⚠️ **주의**: 그래서 지금 `gold` 라는 이름의 클래스가 실제로는 **파란색**입니다.
새로 짜는 코드에서는 `gold` 대신 새로 추가한 **`brand`** 토큰(`text-brand`, `bg-brand`)을 쓰세요.
값은 동일하고(`#5383E8`), 이름이 실제 색과 일치합니다.
기존 `gold` 사용처는 시간 날 때 점진적으로 `brand` 로 바꿔주면 됩니다.

새로 추가된 토큰:
- `brand` / `brand-bright` — 포인트 블루
- `win`(#5383E8) / `lose`(#E84057) — op.gg식 승/패 색상 (승률 표시 등에 사용 예정)

## 6. 새 홈페이지 구조 (HomePage.tsx)

```
┌────────────────────────────────────────────┐
│              TFT.GG  (대형 로고)             │
│   [ KR ▾ | 플레이어 이름 + #KR1   | .GG ]   │  ← 흰색 대형 검색바 (op.gg)
├───────────────────────────┬────────────────┤
│  추천 메타          더보기→ │ KR 랭킹 TOP 10  │
│  [S] 영혼 마법사  🧙🧙🧙   │ 1 Faker 1,850LP │
│  [S] 결투가 리롤  ⚔️⚔️⚔️   │ 2 Guma…        │  ← lolchess 스타일
│  [A] 공허 사수   …        │ …              │
│  (조합 클릭 → 상세 페이지)  │ (클릭 → 전적)   │
└───────────────────────────┴────────────────┘
```

- 데이터 출처: 추천 메타는 `useComps()`(→ `mocks/comps.ts`), 랭킹은 `useLeaderboard('kr','all',1)`(→ `mocks/leaderboard.ts`)
- 로딩/에러 처리는 기존 `QueryBoundary` + `Skeleton` 패턴 그대로 사용

## 7. 건드리지 않은 것

- 페이지 로직, API 계층(`src/api/`), 훅(`src/hooks/`), 목 데이터 — **전부 그대로**입니다.
- 나머지 페이지(전적검색, 데이터 통계, 아이템, 챔피언, 순위, 전략가 등)는 코드 수정 없이 토큰 재매핑으로 자동으로 새 테마가 적용됐습니다.
- 백엔드/파이프라인/ML 폴더는 이번 작업과 무관합니다.
